# mockqt — PyQt5 대역(stub)

PyQt5를 설치하지 않고도 `wizard.py`의 **로직**을 테스트하기 위한 최소 구현입니다.
위젯을 실제로 그리지는 않지만, 목록·표·트리·콤보박스는 실제로 상태를 보관하고
시그널을 발생시키므로 다음을 검증할 수 있습니다.

- 시그널 연결과 핸들러 동작 (체크박스 토글 → plan 반영 등)
- 대화상자가 어떤 데이터로 열리는지
- 버튼 활성/비활성, 상태 문구

PyQt5는 인자를 받을 수 있는 만큼만 슬롯에 넘기는데(초과분 절삭), 이 동작까지
`_base.Signal.emit`에서 흉내내고 있습니다.

CI에서는 PyQt5 휠이 없는 환경도 있으므로 이 대역을 사용합니다. 실제 Qt 렌더링과
xlwings의 DRM 우회는 Windows에서 수동으로 확인해야 합니다.
